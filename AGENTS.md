# Bun TypeScript Template

## Before work

- Run `bun run doctor` and apply the repairs it reports.
- Build, repair, or review `kernel/` or `tests/kernel/` with
  [kernel-work](.agents/skills/kernel-work/SKILL.md).
- Use [repo-gardener](.agents/skills/repo-gardener/SKILL.md) for an operator
  correction, review finding, new gate, unused guidance, or refused name.

## Authority

- For Contract 3 behaviour, read the [contract authority](docs/agents/contract-3.md).
- Before naming a file, folder, test, or commit, read the
  [glossary map](GLOSSARY-MAP.md).

## Coordination context

- When a task needs a private Contract 3 record, use the
  [record owners](docs/agents/contract-3.md#coordination-context).

## Checks

- Use the [check routes](docs/agents/README.md#checks) for focused tests,
  full or timing-sensitive suites, and hosted failures.
- Review a diff using the [review routine](CODING_STANDARDS.md#review-routine).

## Pull requests

- For opening, reviewing, or merging a pull request, follow the
  [pull request workflow](docs/agents/pull-requests.md).
