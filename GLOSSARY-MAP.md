# Glossary map

Each word has one owner. Find the glossary that owns the word you need, and
use its word.

| Glossary        | Owns                                                                                                                         | Where                                                                                    |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| This repository | Recipes and the template's own checks                                                                                        | [GLOSSARY.md](GLOSSARY.md)                                                               |
| Kernel          | The terms its glossary test enforces in kernel files                                                                         | [tests/glossary/term-table.json](tests/glossary/term-table.json)                         |
| Agent ecosystem | Words shared across projects, such as Bootstrap, Template and Generated repository; private, so only its name and owner here | "Agent ecosystem glossary (living)" in Linear. Owner: Engineering, through Linear MAG-64 |

The kernel's term table leaves this repository with the kernel. When it does,
remove its row.
