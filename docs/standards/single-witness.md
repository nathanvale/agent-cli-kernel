# Single Witness

A lesson seen once waits in one of the files below as one bullet: the lesson
as an imperative, then `Witnessed:` and its citation. Put a new lesson in the
file whose subject it matches, in place of `- None yet.` when that line is
there. When a second witness arrives, the lesson moves to a row in the
[rule table](../../CODING_STANDARDS.md#rule-table) and leaves its file; restore
`- None yet.` when no bullet remains.

- [Tests](single-witness-tests.md): how a test is built, what it asserts and what it proves.
- [Lints](single-witness-lints.md): how a lint rule reads code, how its repair is built and where its allowance applies.
- [State and processes](single-witness-state.md): run state, state on disk, locks, file creation and child processes.
- [Tools and gates](single-witness-tools.md): how a gate, a script or a check reads a tool, its output and its inputs.
