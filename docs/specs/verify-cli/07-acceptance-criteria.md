# `verify-cli` specification, part 7 of 11: acceptance criteria

This part belongs to Testing Decisions. Each criterion gives an observable
result and the test that shows it. A test is named by its title, which the
builder uses as written. "Example CLI" is the author skill's example, `moons`,
in a repository laid out as TD1 says. The tag says what has run: `macOS` is
the claim tag "passed on macOS only", with the prototype or the scratch
script; `designed` is "designed and not run". The evidence behind each `macOS`
tag is in [part 10](10-traceability.md#acceptance-criteria).

A criterion that names an exit 70 line passes when `stderr` holds a line
starting `verify-cli: RAW FAIL <id>:` for that id. Other such lines may also
be there.
